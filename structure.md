# Peta Struktur Proyek

Boilerplate company profile berbasis Next.js (App Router, TypeScript, Tailwind). Perbarui file ini setiap kali ada file atau folder yang ditambah, diganti nama, atau dipindah.

## Akar proyek

| Path | Tanggung jawab |
|---|---|
| `CLAUDE.md` | Aturan untuk AI, mengimpor `docs/rules/*.md` |
| `structure.md` | Peta struktur proyek ini |
| `AGENTS.md` | Catatan agen bawaan Next.js |
| `README.md` | Pengantar proyek bawaan scaffold |
| `.env.example` | Contoh variabel lingkungan (`DATA_SOURCE`, `SITE_URL`, `SITE_INDEXING`) |
| `vitest.config.mts` | Konfigurasi Vitest: tes ada di `tests/**/*.test.{ts,tsx}`, JSX otomatis lewat `oxc`, dan `tests/setup/next-mocks.ts` dijalankan sebelum setiap file tes |
| `next.config.ts`, `tsconfig.json`, `eslint.config.mjs` | Konfigurasi Next.js, TypeScript, dan ESLint |
| `THEME.md` (menyusul) | Panduan membuat tema baru dari desain |
| `UPDATING.md` (menyusul) | Cara menarik pembaruan boilerplate ke tema |

## Folder

| Path | Tanggung jawab |
|---|---|
| `docs/rules/` | Salinan aturan yang sudah disesuaikan: `rules.md`, `seo-rules.md`, `seo-for-new-website.md`, `eeat-rules.md` |
| `tests/` | Tes Vitest, mengikuti struktur `src/` (saat ini `tests/lib/text/`, `tests/lib/seo/` (termasuk `site-url.test.ts`, `metadata.test.ts`, `json-ld.test.ts`), `tests/lib/markdown/`, `tests/core/application/` termasuk `schemas.test.ts` dan `site-queries.test.ts`, `tests/infrastructure/images/`, `tests/content/packs/` berisi `general-media.test.ts` dan `general.test.ts`, `tests/lib/site/` berisi `whatsapp.test.ts`, `tests/server/` berisi `container.test.ts` dan `site/` (`navigation.test.ts`, `site-context.test.ts`, `models/pages.test.ts`, `models/catalog.test.ts`), `tests/components/` berisi tes komponen `.tsx` yang dirender dengan `renderToStaticMarkup`, saat ini `setup.test.tsx`) |
| `tests/fixtures/` | Data bantu tes, bukan file tes. `content-pack.ts` berisi `buildTestPack()` yang mengembalikan paket konten valid baru (siteName "Nusa Karya") di setiap panggilan, dengan intro seksi untuk kesepuluh `SECTION_KEYS`. `site.ts` berisi `buildTestQueries(theme?)` (`SiteQueries` dari `buildTestPack()` dan `themeConfig` yang digabung dengan tema parsial), `buildTestEnv(overrides?)` (siteUrl `https://nusakarya.example`, indexing aktif, mode demo), dan `buildTestContext({ env?, theme? })` yang mengembalikan `SiteContext` lengkap |
| `tests/setup/` | `next-mocks.ts`: setup Vitest yang me-mock `next/image` (menjadi `<img>` polos tanpa prop non-DOM seperti `priority` dan `fill`), `next/link` (menjadi `<a>`), dan `next/navigation` (`usePathname` selalu `"/"`, `useRouter` berisi `push`, `replace`, `prefetch` kosong). Berupa `.ts` memakai `createElement`, supaya `.tsx` hanya ada di `tests/components/` |
| `public/` | Aset statis |
| `public/demo/<paket>/` | Gambar demo WebP per paket konten, satu file per kunci media (`<kunci>.webp`, maksimal 100 KB). Saat ini ada `public/demo/general/` berisi 50 gambar: 41 foto Pexels, logo Arunika Solusi, dan 8 logo mitra fiktif dengan latar transparan |
| `docs/credits/` | Kredit gambar per paket konten. `general.md` mencatat fotografer, halaman Pexels, dan lisensi setiap kunci media |
| `supabase/migrations/` (menyusul) | Skema, RLS, fungsi, bucket storage |
| `supabase/seed.sql` (menyusul) | Hasil generate dari paket konten, tidak diedit manual |
| `scripts/` | `import-demo-image.ts`: CLI `npm run image:import -- <file-sumber> <paket> <nama-file> [--logo]` yang mengonversi gambar ke WebP, menulis `public/demo/<paket>/<nama-file>.webp`, dan mencetak `<lebar> <tinggi> <ukuran-byte>`. Skrip create-theme, generate-seed, create-admin, generate-favicon menyusul |

## src/

| Path | Tanggung jawab |
|---|---|
| `src/app/` | Rute Next.js. Saat ini masih berisi `layout.tsx`, `page.tsx`, `globals.css` bawaan scaffold |
| `src/app/(site)/` (menyusul) | Website publik |
| `src/app/admin/` (menyusul) | Panel admin |
| `src/core/domain/` | Entity dan interface repository per modul, tanpa impor dari infrastruktur, React, Next, atau Supabase. Satu tipe atau interface per file. Subfolder: `shared/` (`media-asset`, `faq-item`, `call-to-action`, `module-key`, `section-key`), `settings/` (`site-settings` dan repository-nya), `page/` (`home-content`, `section-intro`, `about-content` (ketiganya membawa `metaTitle`, dan home serta intro juga `metaDescription`), `company-vision` bersama `CompanyValue`, `legal-page` bersama `LEGAL_SLUGS` dan `LegalSlug`, `page-content-repository`), `service/`, `portfolio/`, `team/`, `stat/`, `testimonial/`, `partner/`, `article/` (`Article`, `ArticleWithAuthor`, `ArticlePage`), `content-block/` (`ContentBlock` bersama `ContentBlockItem`), `content-pack/` (`ContentPack`), `theme/` (`theme-config.ts`: `ThemeConfig`, `ContentBlockDefinition`, `ContentBlockItemField`), dan `repositories.ts` (tipe `Repositories`). Kontrak repository: daftar terurut `sortOrder` naik, artikel terurut `publishedAt` terbaru (`ArticleRepository` punya `listPublished` berhalaman dan `listAllPublished` tanpa halaman) |
| `src/core/application/` | Use case dan skema Zod. Saat ini baru `schemas/`: `shared-fields.ts` (slug, meta title, meta description, media, FAQ, CTA), `site-schemas.ts` (pengaturan situs, beranda, intro seksi, tentang, visi, halaman hukum, blok konten), `catalog-schemas.ts` (layanan, portofolio, tim, statistik, testimoni, mitra), `article-schema.ts`, dan `content-pack-schema.ts` (paket konten dengan cek slug unik, `authorId` yang ada di tim, intro untuk kesepuluh `SECTION_KEYS` tanpa duplikat, dan `metaTitle` home, intro, serta tentang yang memenuhi aturan judul penuh). Skema artikel menolak slug cadangan `halaman`. `site/` berisi query situs yang menghormati modul aktif tema: `module-guard.ts` (`isModuleEnabled`, `isModuleKey`), `page-queries.ts` (pengaturan, beranda, tentang, visi, intro seksi, halaman hukum, blok konten), `catalog-queries.ts` (layanan, portofolio, tim, statistik, testimoni, mitra, ditambah `getAuthor(id)` dan `getStatByKey(key)` yang tidak dikunci modul `team` dan `stats` karena kotak penulis memakainya), `article-queries.ts` (`ARTICLES_PER_PAGE`, `listAllArticles` untuk semua artikel terbaru, daftar artikel berhalaman, detail dengan penulis, artikel terkait), dan `site-queries.ts` (`createSiteQueries` menggabungkan semuanya). Use case lain menyusul |
| `src/infrastructure/supabase/` (menyusul) | Client, repository, storage |
| `src/infrastructure/fixtures/` | `fixture-repositories.ts`: `createFixtureRepositories(pack)` membuat `Repositories` yang membaca `ContentPack` di memori, mematuhi kontrak urutan (tanpa mengubah array paket) |
| `src/infrastructure/images/` | `optimize-webp.ts`: `optimizeToWebp(input, { maxWidth, maxBytes })` mengubah gambar ke WebP dengan sharp (tanpa memperbesar, transparansi tetap, kualitas turun bertahap lalu lebar dikecilkan sampai di bawah batas byte), beserta konstanta `PHOTO_MAX_WIDTH` (1920), `LOGO_MAX_WIDTH` (600), dan `MAX_IMAGE_BYTES` (102400) |
| `src/content/packs/index.ts` | `CONTENT_PACKS` (`Record<string, ContentPack>`): daftar paket konten yang bisa dipilih lewat `themeConfig.contentPack`. Saat ini berisi `general` |
| `src/content/packs/<paket>/` | Paket konten demo, satu file per bagian isi. Paket `general` berisi perusahaan fiktif Arunika Solusi (konsultan manajemen dan transformasi digital di Jakarta Selatan): `media.ts` (`GENERAL_MEDIA_KEYS`, tipe `GeneralMediaKey`, dan `generalMedia` berisi 50 gambar demo dengan alt bahasa Indonesia), `settings.ts`, `home.ts`, `section-intros.ts` (kesepuluh `SECTION_KEYS`, masing-masing dengan `metaTitle` dan `metaDescription`), `about.ts`, `vision.ts` (4 misi, 4 nilai), `services.ts` (6 layanan), `portfolio.ts` (6 proyek), `team.ts` (4 anggota), `stats.ts` (4 statistik, termasuk `completed_projects` dan `years_experience`), `testimonials.ts` (5), `partners.ts` (8), `content-blocks.ts` (satu blok untuk setiap definisi di `themeConfig`), `legal-pages.ts` (privasi, syarat dan ketentuan, kebijakan editorial, dengan kontak diambil dari `settings.ts`), `articles/` (satu file per artikel: `cara-menyusun-sop-umkm.ts`, `langkah-awal-transformasi-digital.ts`, `menentukan-kpi-operasional.ts`), dan `index.ts` yang menggabungkan semuanya menjadi `generalPack`. Semua gambar dirujuk dari `generalMedia` |
| `src/server/actions/` (menyusul) | Server actions publik dan admin |
| `src/server/container.ts` | `getSiteQueries()` memilih sumber data dari `DATA_SOURCE` (kosong atau tidak diisi berarti `demo`). `demo` membuat `SiteQueries` dari repository fixtures yang membaca `CONTENT_PACKS[themeConfig.contentPack]` dan melempar error bila paketnya tidak terdaftar. `supabase` melempar error "belum tersedia" sampai Rencana 3, nilai lain melempar error nilai tidak dikenal |
| `src/server/site/` | Konteks situs untuk website publik, hanya `.ts`: `site-env.ts` (`getSiteEnv()` membaca `SITE_URL`, `SITE_INDEXING`, dan `DATA_SOURCE` dari `process.env` saat dipanggil, `isDemo` true bila sumber data kosong atau `demo`), `navigation.ts` (`buildNavigation(enabledModules)` menyusun Beranda, Tentang, Layanan, Portofolio, Artikel, Kontak dengan hanya modul aktif yang muncul, serta `LEGAL_LINKS` untuk tiga halaman hukum dengan `rel` privasi dan syarat), dan `site-context.ts` (`getSiteContext(queries, env, theme)` menggabungkan pengaturan, tema, env, `seoSite` dengan gambar OG bawaan `/opengraph-image`, navigasi, URL WhatsApp, serta JSON-LD Organization dan WebSite). Subfolder `models/` berisi model halaman, fungsi async murni `(queries, context)` yang mengembalikan data siap render beserta `seo` (`PageSeoResult`: `metadata`, `jsonLd`, `breadcrumbs`): `page-seo.ts` (`buildPageSeo`, `requireSectionIntro` yang melempar `Error` bila intro wajib hilang, `collectSectionIntros`, `takeOthers`, `HOME_BREADCRUMB`), `home.ts` (`getHomePageModel`: beranda tanpa JSON-LD Organization dan WebSite karena sudah dari layout, `featuredPortfolio` dan `latestArticles` maksimal 3, `blocks` hanya blok yang dideklarasikan tema dan punya data), `about.ts` (`getAboutPageModel`, Person per anggota tim terbit), `contact.ts` (`getContactPageModel`), `legal.ts` (`getLegalPageModel`, `null` untuk slug tidak dikenal), `services.ts` dan `portfolio.ts` (model daftar dan detail beserta `listServiceSlugs` dan `listPortfolioSlugs`; `null` bila modul mati atau slug tidak ada, `others` maksimal 3 item lain urut `sortOrder`, gambar OG detail dari `<rute>/opengraph-image`) |
| `src/lib/text/` | Utilitas teks murni: `slug.ts` berisi `slugify`, `isValidSlug`, `RESERVED_ARTICLE_SLUGS` (`halaman`), dan `isReservedArticleSlug` |
| `src/lib/seo/` | `limits.ts` (batas panjang dan jumlah untuk SEO), `title.ts` (`titleSuffix`, `maxMetaTitleLength`, `buildPageTitle`), `content-checks.ts` (`runContentChecks` dan `hasBlockingErrors`, pesan dalam bahasa Indonesia), `site-url.ts` (`resolveSiteUrl` bawaan `http://localhost:3000` tanpa garis miring akhir dan melempar bila bukan URL http atau https, `resolveIndexing` true hanya untuk `on`, `absoluteUrl` dan `absoluteAssetUrl` yang meneruskan URL aset yang sudah absolut), `metadata.ts` (`buildMetadata(input, site)` membangun `Metadata` Next: `title.absolute`, canonical absolut, robots yang mati bila indexing mati atau `forceNoIndex`, Open Graph 1200x630 berlokale `id_ID`, dan Twitter Card; tipe `SeoSite` dan `PageSeoInput`), `json-ld.ts` (`serializeJsonLd` yang meloloskan `<`, U+2028, dan U+2029, serta builder JSON-LD murni: Organization dengan ContactPoint dan publishingPrinciples, WebSite, BreadcrumbList, Service, CreativeWork portofolio, BlogPosting, Person, dan FAQPage yang bernilai `null` bila kosong; `sameAs`, `foundingDate`, `dateCreated`, `logo`, dan `image` tidak dikeluarkan bila datanya tidak ada). Semuanya fungsi murni tanpa React dan tanpa impor runtime Next |
| `src/lib/site/` | `whatsapp.ts`: `buildWhatsAppUrl(number, message)` membangun `https://wa.me/<nomor>?text=<pesan ter-encode>` |
| `src/lib/markdown/` | Analisis markdown murni: `code-blocks.ts` (membuang blok kode berpagar), `headings.ts` (`extractHeadings`, `analyzeHeadings`), `words.ts` (`countWords`), `links.ts` (`countLinks` internal dan eksternal) |
| `src/config/theme.ts` | `themeConfig`: nama tema, paket konten, modul aktif, dan definisi blok konten |
| `src/hooks/` (menyusul) | Hook client |
| `src/styles/` (menyusul) | `tokens.css`, `globals.css`, `fonts.ts` |
| `src/components/ui/` (menyusul) | Komponen dasar, dipakai publik dan admin |
| `src/components/site/layout/` (menyusul) | Header, Footer, WhatsAppButton |
| `src/components/site/sections/` (menyusul) | Hero, ServicesSection, PortfolioSection, dan lainnya |
| `src/components/site/views/` (menyusul) | HomeView, AboutView, ArticleDetailView, dan lainnya |
| `src/components/site/contract/` (menyusul) | Komponen wajib SEO dan E-E-A-T |
| `src/components/admin/` (menyusul) | Tata letak dan form admin |
| `src/components/skeletons/` (menyusul) | RouteSkeleton dan bagian-bagiannya |
